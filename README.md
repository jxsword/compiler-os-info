# Compiler and OS Information Detector

一个简单的C语言项目，用于检测和显示编译器和操作系统的详细信息。

## 功能特性

- ✅ 检测编译器类型和版本（支持GCC、Clang、MSVC）
- ✅ 检测操作系统类型和版本（Windows、macOS、Linux）
- ✅ 运行时动态检测操作系统信息
- ✅ 支持多种编译器和平台
- ✅ 使用CMake构建系统

## 支持的编译器和平台

### 编译器

- GCC (GNU Compiler Collection)
- Clang (LLVM编译器)
- MSVC (Microsoft Visual C++)
- MinGW-w64 GCC

### 操作系统

- Windows 10/11
- Ubuntu/Linux
- macOS
